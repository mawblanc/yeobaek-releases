# 여백

소설을 쓰고, 휴대폰과 PC에서 같은 이야기를 이어 가는 집필 공간입니다.

**[여백 다운로드](https://yeobaek-writer.web.app)**

- [Android APK 바로 다운로드](https://github.com/mawblanc/yeobaek-releases/releases/download/v1.1.5/Yeobaek-1.1.5-Android.apk)
- [Windows 64비트 ZIP 바로 다운로드](https://github.com/mawblanc/yeobaek-releases/releases/download/v1.1.5/Yeobaek-1.1.5-Windows-x64.zip)

Android는 내려받은 APK를 열어 설치합니다. Windows는 ZIP의 압축을 모두 푼 뒤 `여백.exe`를 실행합니다.

처음 쓰는 기기에서 전달받은 초대 코드로 계정을 만들고, 다른 기기에서도 같은 계정으로 로그인하면 이어 쓸 수 있습니다. 휴대폰만 또는 PC만 사용해도 됩니다. 각자의 원고와 노트는 계정별로 분리됩니다.

이 저장소는 설치 파일 배포용입니다. 개인 원고와 사용자 계정 데이터는 포함하지 않습니다.
